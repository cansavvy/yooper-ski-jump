# A Yooper Ski Jumping Legacy

This is the source files for an online book written by Craig Savonen.
You can see the book at [yooperskijumping.com](https://yooperskijumping.com/).

It is available on Amazon and also you can download the [Kindle compatible epub file from here for free](https://raw.githubusercontent.com/cansavvy/yooper-ski-jump/refs/heads/main/Yooper-Ski-Jumping-Legacy.epub).

For inquiries related to the book, you can [email Craig](clsavonen@gmail.com).
